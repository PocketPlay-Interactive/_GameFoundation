# Game Foundation Samples

Open a sample scene, press Play, then read the Console logs and inspector fields.

| Sample | Scene | Shows |
| --- | --- | --- |
| EditorCools | `EditorCools/Scenes/Demo.unity` | Dropdowns, min/max slider, inspector buttons |
| ExtensionData | `ExtensionData/Scenes/Demo.unity` | Runtime extension data save/load |

These samples are intentionally small. They are meant as copyable usage snippets, not production prefabs.
