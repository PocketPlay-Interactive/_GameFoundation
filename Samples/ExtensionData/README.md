# ExtensionData Sample

Open `Scenes/Demo.unity` and press Play.

`ExtensionDataDemo` writes values into `RuntimeStorageData.PLAYER.ExtensionData`, saves them, then reads them back.

It covers:

- `Set` / `Get`.
- `SetInt` / `GetInt`.
- `SetFloat` / `GetFloat`.
- `SetBool` / `GetBool`.
- JSON save/load through `JsonUtility`.
